Keys are shown as their first and last 5 characters and are never revealed. To replace one, click the field and paste the new key (Enter or click away to save, Esc to cancel). A config/keys.json next to the app pre-fills empty fields; a key entered here overrides it, and Remove goes back to it.

How to use Interview Copilot

How the app hears the interviewer

1 · Install
  1. Open the .dmg for your Mac: arm64 for Apple silicon (M1 and later), x64 for Intel. To check, choose Apple menu → About This Mac.
  2. Drag Interview Copilot into Applications.
  3. The first open is blocked with "Apple could not verify … is free of malware" unless the build was notarized by Apple. That is macOS Gatekeeper, not a virus. To open it anyway:
    • macOS 15 and later: double-click the app once (it is refused), then go to System Settings → Privacy & Security, scroll to the Security section, and click Open Anyway next to "Interview Copilot". Confirm with your password.
    • macOS 14 and earlier: right-click the app → Open → Open.
    • Any version, in Terminal: xattr -dr com.apple.quarantine "/Applications/Interview Copilot.app" then open the app normally.
    This is needed once per Mac. Builds signed with a Developer ID and notarized open without any of this.
  4. macOS asks for permissions the first time each one is needed. Click Allow:
    • System Audio Recording: on the first Start. This is how the app hears the interviewer.
    • Microphone: on the first Start. This records your own voice.
    • Screen Recording: only the first time you use Snap (screenshot).
    If you clicked Don't Allow, turn the app on in System Settings → Privacy & Security → the matching list, then quit and reopen the app.

Needs macOS 12 or later. Recording the system audio directly needs macOS 14.2 or later. On older macOS, see Older macOS: BlackHole under Troubleshooting.

2 · Set up once (App tab)
  1. API keys
    • Add a key for at least one AI provider: Anthropic (Claude), OpenAI or Gemini.
    • A Deepgram key is only needed if you choose Deepgram under Transcription.
  2. Transcription (speech to text)
    • Offline (default): click Download once to get the model (about 670 MB). It runs on this computer, works without internet and sends nothing anywhere. One model covers English, Romanian and Portuguese.
    • Deepgram: uses the cloud with an API key instead. Lighter on the CPU.
  3. AI answers: pick the Provider you have a key for, then a Model.
  4. Capture
    • System audio source: leave it on Automatic. It records the Mac's system audio output.It records Windows system audio.It mirrors your default output.
    • Microphone (you): System default microphone or your headset mic. Never pick BlackHole here.
    • Also transcribe my microphone: keep this on to save your own answers in the PDF report.
    • Answer automatically: on = an answer starts as soon as a question is detected. Off = you decide when to press Send.
  5. Network: only if OpenAI, Anthropic, Gemini, Deepgram or the model download are blocked where you are. Enter your proxy address, then click Check proxy.
  6. Appearance: theme and font, whatever you like.
3 · Before each interview (Profile tab)
  1. Create a profile for the company or role: click New, or Duplicate an existing one.
  2. Paste your Resume and the Job description. Adjust the Custom prompt, Answer style and Meeting language if needed.
  3. For a second or later round, add notes under Earlier rounds, or import the PDF report from the previous round.
4 · During the interview
  1. Join the call in Zoom, Teams, Meet or any other app, and make sure you can hear the interviewer. Any speaker or headphones work. Nothing needs to be routed. Any output device works. If you change the output device mid-call, press Stop and then Start.
  2. In the panel, pick the profile and press Start. The bar above the transcript shows what the app listens to, for example Interviewer · Mac system audio output (MacBook Pro Speakers)System audioInterviewCopilotMonitor.
  3. The dot in the top-left corner shows the audio link:
    • Green: connected.
    • Pulsing green: hearing the interviewer.
    • Red: disconnected or an error.
  4. The interviewer's words appear in Question to send. Edit them if needed, then press Enter or Send. The answer streams in, with code in the panel on the right.
  5. For a coding or on-screen question, click Snap for a screenshot, or Attach / paste / drop a file. Then send.
  6. If an answer fails or is cut off, press ↻ Retry. ‹ Prev and Next › flip through earlier answers.

Troubleshooting
"No sound is reaching …" / nothing is transcribed
  1. Make sure you can hear the interviewer on this Mac and the meeting isn't muted. The app records exactly what the Mac plays.
  2. Check the permission: System Settings → Privacy & Security → Screen & System Audio Recording → System Audio Recording Only → turn on Interview Copilot. Then quit and reopen the app.
  3. In Setup → App → Capture, set System audio source to Automatic. If it is set to BlackHole, the app only hears what is routed to BlackHole.
  4. Press Stop, then Start.

The meeting must play through Windows' default output device and must not be muted. Leave System audio source on Automatic, then press Stop and Start.

The meeting must play through the default output. If you changed outputs, press Stop and Start. If it still fails, open pavucontrol → Recording and set Interview Copilot to Monitor of <your output>.

"Apple could not verify … is free of malware" / "is damaged and can't be opened"

Gatekeeper blocks apps that Apple has not notarized; the app is fine. Open it once with Open Anyway (System Settings → Privacy & Security → Security) on macOS 15+, right-click → Open on older macOS, or remove the quarantine flag in Terminal: xattr -dr com.apple.quarantine "/Applications/Interview Copilot.app". If the app was already moved to the Trash by macOS, put it back in Applications first.

The permission prompt never appeared

Open System Settings → Privacy & Security → Screen & System Audio Recording. Under System Audio Recording Only, click +, add Interview Copilot from Applications and turn it on. Then quit and reopen the app.

Older macOS (before 14.2): BlackHole
  1. Install BlackHole: brew install --cask blackhole-2ch, then restart the Mac.
  2. Open Audio MIDI Setup → + → Create Multi-Output Device. Tick your speakers or headphones and BlackHole 2ch. Set your speakers as the Primary Device and turn on Drift Correction for BlackHole.
  3. Right-click the Multi-Output Device → Use This Device For Sound Output. In Zoom or Teams, set the Speaker to that device too.
  4. In Setup → Capture, leave Automatic or pick BlackHole 2ch. The Mac's volume keys don't work with a Multi-Output Device; set the volume in Audio MIDI Setup instead.
Words appear late, or the computer gets slow during the call

Offline transcription runs the model on your CPU. Words arrive about a second after they are spoken and the sentence settles when the speaker pauses. If the computer struggles, close other heavy apps or switch Transcription to Deepgram in Setup → App.

"The transcription model is not downloaded" / the download fails

Setup → App → Transcription → Download. The files come from huggingface.co and github.com; if those are blocked where you are, set a proxy under Network first — the download uses it. A stopped download continues where it left off.

"Deepgram socket error" or answers never arrive

Check the keys in Setup → App → API keys. If those services are blocked on your network, set a proxy under Network and click Check proxy.

Snap (screenshot) fails

Allow Screen Recording for Interview Copilot in System Settings → Privacy & Security, then quit and reopen the app.Try again, or paste a screenshot instead: Win+Shift+S on Windows, then Ctrl+V in the question box.
